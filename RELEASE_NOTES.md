# APS update

APS can now be installed once and updated from its tray menu. Use **Check for
updates** to review a release, download it, and restart into the new version. Installed
copies also check quietly in the background and show a tray notification when an
update is ready.

Profiles remain in your user settings folder through updates. The standalone EXE is
still available for portable use; install with `APS-AudioProfileSystem-win-Setup.exe` to
enable the managed update path.
